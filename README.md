# 실행 체크리스트 — 바탕화면 앱

중고장비 매매장부와 같은 방식(PWA)입니다. 설치하면 바탕화면·홈 화면에 아이콘이 생기고, 주소창 없는 독립 창으로 열리며 인터넷이 끊겨도 동작합니다.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 본체 |
| `manifest.webmanifest` | 앱 이름·아이콘·창 모양 |
| `sw.js` | 오프라인 캐시 |
| `icon-192.png` / `icon-512.png` / `icon-maskable.png` | 아이콘 |

## 올리기

폴더 통째로 GitHub Pages 저장소에 넣고 push 합니다. 예를 들어 `checklist/` 폴더에 두면 주소는

```
https://5807944-alt.github.io/checklist/
```

**file:// 로 열면 설치가 안 됩니다.** 브라우저가 서비스워커를 https 에서만 허용하기 때문입니다. 로컬에서 확인만 할 때는 폴더에서 `python -m http.server` 를 띄우고 `http://localhost:8000` 으로 여세요.

## 설치

**PC (Chrome · Edge)** — 주소창 오른쪽 설치 아이콘, 또는 앱 헤더의 `설치` 버튼. 설치 후 바탕화면과 시작 메뉴에 아이콘이 생깁니다.

**안드로이드 (Chrome)** — 헤더의 `설치` 버튼, 또는 메뉴 → 홈 화면에 추가.

**아이폰 (Safari)** — 공유 → 홈 화면에 추가. (iOS는 `설치` 버튼이 뜨지 않습니다)

## 기존 데이터 옮기기

기록은 **주소마다 따로** 저장됩니다. 지금 `checklist.html` 파일로 쓰고 계셨다면 그 데이터는 새 주소로 자동으로 넘어오지 않습니다.

1. 쓰던 파일을 열고 ⚙ → `내보내기` → JSON 저장
2. 새 주소에서 ⚙ → `가져오기` → 그 JSON 선택

## 앱을 고친 뒤에

`sw.js` 맨 위의 `CACHE = 'checklist-v1'` 숫자를 올리고 push 하세요. 올리지 않으면 캐시된 옛 버전이 계속 열립니다.
